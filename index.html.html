Storage Class: S3 Standard | Static Hosting: Enabled (index.html) | Policy: s3:GetObject - Public

🪣 What I Built

Created S3 bucket, configured static website hosting, attached bucket policy for public read, uploaded portfolio files (index.html, error.html). Same as hosting any static site globally with 11 nines durability.

🔒 S3 Access Control

Learned Block Public Access, ACLs disabled, Bucket Owner Enforced, and Bucket Policy JSON. Implemented least privilege - only s3:GetObject allowed for public.

☁️ Storage Classes

S3 Standard for website, S3-IA for backups, Glacier for archive. Understood lifecycle policies and cost optimization.

📁 How to Deploy (Steps in README)

1. aws s3 mb s3://amresh-portfolio-2026
2. Enable Static Website Hosting -> Index: index.html
3. Add policy.json (PublicRead)
4. aws s3 cp . s3://amresh-portfolio-2026/ --recursive
5. Open S3 Website Endpoint - Live!
